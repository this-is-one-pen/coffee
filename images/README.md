# 白猫の成長画像

正解数に応じて、白猫が10問ごとに成長します。画像は、このフォルダに次のファイル名で置いてください。
ファイルがない段階では、画面に「画像準備中」と表示されます。

| ファイル名 | ステージ | 表示されるタイミング(正解数) |
| --- | --- | --- |
| `stage1.jpg` | 生まれて間もない子猫 | 0問〜 |
| `stage2.jpg` | 小さな子猫 | 10問〜 |
| `stage3.jpg` | やんちゃな子猫 | 20問〜 |
| `stage4.jpg` | 若い猫 | 30問〜 |
| `stage5.jpg` | ほぼ大人の猫 | 40問〜 |
| `stage6.jpg` | 大人の猫 | 50問〜 |
| `stage7.jpg` | 立ち上がる猫 | 60問〜 |
| `stage8.jpg` | 二足歩行する猫 | 70問〜 |
| `stage9.jpg` | エプロン姿の猫 | 80問〜 |
| `stage10.jpg` | カフェでくつろぐ猫(最終) | 90問〜 |

正解数の区切りは、`growth.js` で変えられます。

## 画像生成のコツ(Gemini用)

最終形態の `stage10.jpg` と同じ猫・同じカフェに見えるよう、同じ会話の中で続けて生成します。
比率は16:9の横長、「写真のようにリアルな写真風イラスト」と指定します。
