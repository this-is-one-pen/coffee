## 画像生成のプロンプト例(Gemini用)

最終形態の `stage5.jpg` と、同じ猫・同じ店内に見えるようにするための例です。
画像の比率は、16:9で横長にしてください。

- **stage1(子猫)**: 写真のようにリアルな写真風イラスト。木の内装のおしゃれなカフェの、木のテーブルの上に座る、生後2〜3か月の白い子猫。大きな丸い目、小さな体、ふわふわの毛。窓から自然光が入る。背景は少しぼかす。16:9。
- **stage2(少し大きくなった猫)**: 写真のようにリアルな写真風イラスト。同じカフェのテーブルの上に座る、生後6か月ほどの白い若い猫。まだ少し小さいが、顔つきが引き締まってきている。窓からの自然光。16:9。
- **stage3(大人の猫)**: 写真のようにリアルな写真風イラスト。同じカフェのテーブルに座る、落ち着いた大人の白い短毛の猫。緑がかったグレーの瞳。テーブルの上にカップが置いてある。16:9。
- **stage4(二足歩行する猫)**: 写真のようにリアルな写真風イラスト。同じカフェの店内を、人間のように二本足で立って歩く大人の白い猫。前足で小さなカップを持っている。背景に木のカウンターと観葉植物。16:9。

画像を作ったら、`stage1.jpg` 〜 `stage4.jpg` の名前で、このフォルダに保存してください。
