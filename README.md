# コーヒーインストラクター 練習クイズ

コーヒーインストラクター(1級編・マスター編)の対策用に作った、ブラウザだけで動くクイズゲームです。ビルドやインストールは不要です。

問題は一般的なコーヒーの知識から作ったオリジナルの練習問題で、実際の試験問題ではありません。

## 使い方

`index.html` をブラウザで開くだけで動きます。

## 問題の構成

9カテゴリに、各100問ずつ、合計900問を収録しています。

- **1級編**: 歴史・文化、栽培・品種、精製・生豆、焙煎、抽出、成分・品質
- **マスター編**: 商品設計、生豆鑑定、品質管理

模擬テストは、全カテゴリ(900問)からランダムに100問を出題します。

## 白猫の成長

正解数に応じて、白猫が10問ごとに子猫から成長していきます(全10段階)。画像は `images/` に置きます。詳しくは `images/README.md` を見てください。

## 問題の追加・変更

`data-*.js` を編集してください。各行は `[問題文, 正解, 誤答1, 誤答2, 誤答3, 解説]` の形式です。選択肢は出題のたびにシャッフルされます。

## ファイル構成

- `index.html` … 画面の土台
- `style.css` … 見た目
- `app.js` … クイズの動作(出題、採点、結果、ベストスコア保存)
- `data-*.js` … カテゴリごとの問題データ
- `questions.js` … 問題データを読み込み、カテゴリにまとめる
- `growth.js` … 白猫の成長ステージの設定
- `images/` … 白猫の画像

## 開発と公開の方針

- 開発中はプライベートリポジトリで作業します。
- 公開するときは、パブリックリポジトリに完成版を置き、GitHub Pagesで公開します。

## リポジトリの使い分け

- **作業用(非公開)**: `this-is-one-pen/test` … 開発はここで行う(`origin`)。
- **公開用(Public)**: `this-is-one-pen/coffee` … 公開したい状態になったときだけ反映する(`coffee`)。公開ページは GitHub Pages(https://this-is-one-pen.github.io/coffee/)。

公開するときは、作業用で動作確認をしてから、次のコマンドで公開用へ反映します。

```
git push coffee main
```

反映の1〜2分後に、公開ページが更新されます。
