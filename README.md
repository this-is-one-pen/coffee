# コーヒーインストラクター1級 練習クイズ

コーヒーインストラクター1級の対策用に作った、ブラウザだけで動くクイズゲームです。ビルドやインストールは不要です。

問題は一般的なコーヒーの知識から作ったオリジナルの練習問題で、実際の試験問題ではありません。

## 使い方

`index.html` をブラウザで開くだけで動きます。

## 問題の構成

6カテゴリ(歴史・文化、栽培・品種、精製・生豆、焙煎、抽出、成分・品質)に、各100問ずつ、合計600問を収録しています。模擬テストは、全カテゴリからランダムに100問を出題します。

## 白猫の成長

正解数に応じて、白猫が子猫から成長していきます。画像は `images/` に置きます。詳しくは `images/README.md` を見てください。

## 問題の追加・変更

`data-*.js` を編集してください。各行は `[問題文, 正解, 誤答1, 誤答2, 誤答3, 解説]` の形式です。選択肢は出題のたびにシャッフルされます。

## ファイル構成

- `index.html` … 画面の土台
- `style.css` … 見た目
- `app.js` … クイズの動作(出題、採点、結果、ベストスコア保存)
- `data-*.js` … カテゴリごとの問題データ
- `questions.js` … 問題データを読み込み、カテゴリにまとめる
- `growth.js` … 白猫の成長ステージの設定
- `images/` … 白猫の画像
