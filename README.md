# コーヒーインストラクター1級 練習クイズ

コーヒーインストラクター1級の対策用に作った、ブラウザだけで動くクイズゲームです。ビルドやインストールは不要です。

問題は一般的なコーヒーの知識から作ったオリジナルの練習問題で、実際の試験問題ではありません。

## 使い方

`index.html` をブラウザで開くだけで動きます。

## 問題の追加・変更

`questions.js` を編集してください。カテゴリごとに、問題文・選択肢・正解の番号(0始まり)・解説を書きます。

## ファイル構成

- `index.html` … 画面の土台
- `style.css` … 見た目
- `app.js` … クイズの動作(出題、採点、結果、ベストスコア保存)
- `questions.js` … 問題データ

## 開発と公開の方針

- 開発中はプライベートリポジトリで作業します。
- 公開するときは、パブリックリポジトリに完成版を置き、GitHub Pagesで公開します。
